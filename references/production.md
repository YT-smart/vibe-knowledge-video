# 制作技术与踩过的坑

## 架构

```
项目目录/
├── video.py        ← 从 example_video.py 复制来改：镜头函数 + SCENES/SUBS/LABELS/sound()
├── vkit.py         ← 引擎（复制，不要改；要加通用能力就改技能里的原件）
├── sfx.py          ← 音效与混音
├── 分镜脚本.md
├── bgm.m4a         ← 从技能 assets/ 复制来的固定背景音乐（用户要换就替换）
└── build/
    ├── frames/00000.png …   ← 逐帧 PNG
    └── audio.wav
```

渲染方式：Python + Pillow 逐帧画在 3840×2160 画布上（2 倍超采样抗锯齿），缩小到 1080p。辉光层是 960×540 的独立图层，模糊两次后叠加。然后乘上暗角、加颗粒，用 `multiprocessing` 多进程并行出 PNG，最后由 ffmpeg 合成 x264 视频。

### 镜头函数怎么写

```python
def my_scene(cv, t):
    a = window(t, 31.0, 40.0, 0.6, 0.6)        # 本镜头整体淡入淡出
    p = ease((t - 32.0) / 2.0)                  # 某个动画的进度 0→1
    rect(cv, 500, 300, 500 + 400 * p, 340, fill=GOLD, a=a)
    rich(cv, [("第 ", DIM, 24, 'song'), ("12", GOLD, 54, 'geo', True), (" 格", DIM, 24, 'song')], 1180, 330, 'l', a)
```

- 所有动画都是 t 的**纯函数**：同一个 t 永远画出同一帧，所以可以任意跳帧预览、并行渲染。随机量都用固定种子预先生成（例如 `STARS`、`CELL_DOTS`）。
- 用 `window()` 管理出现时段，用 `ease()` 做缓动，用 `lerp()` / `lerpc()` 做位置和颜色插值。
- 同一段时间里有几个子画面接力（例如棋盘 → 方格 → 双柱），就在同一个函数里各用一个 `window`，并让它们重叠 0.2~0.4 秒做交叉淡化。
- 字幕、角标、水印由引擎统一画，镜头函数不用管。

### 透明度的实现（重要）

PIL 在 RGB 图上画不出半透明，所以 `a` 是**把颜色和背景色混合**（`mix`）来模拟的。后果是：
- 只在深色纯底上成立。元素叠在别的元素上淡入时，看起来是「变暗」而不是「变透明」。需要真的遮挡时，先画一个底色块（`hud_box`）。
- 背景色变化时（例如夜空过渡），要通过 `bg_color(t)` 让画布知道当前底色。

## 性能与时间预估

- 1080p、2 倍超采样，单核约 **0.8 秒/帧**。135 秒的视频有 4065 帧，约需 4065 × 0.8 ÷ 核数 秒（2 核约 55 分钟，8 核约 15 分钟）；编码另需几分钟到十分钟。开始前先 `os.cpu_count()` 算一下，告诉用户预计时间，然后**放后台跑**。
- `preview` 只渲染几帧，几秒钟就出结果：改完任何东西都先 preview 自查。
- 样片只渲染要看的那一段：`sample 0 31`。

## 编码与文件大小

- 颗粒噪点会让视频**极难压缩**：crf 17 + slow 编出来是 236MB/30 秒。现在的默认参数是 `-crf 21 -tune grain -maxrate 12M`，约 1.5MB/秒（135 秒约 200MB），画质很好，各大平台都能传。
- 需要小文件时用 `--lite`（crf 26 + maxrate 5M，约 0.6MB/秒），或者把 `finish(grain=…)` 调小。
- 不要用 `-preset slow`：带颗粒的画面编码很慢，medium 已经够好。

## 音频

- **固定背景音乐**：本系列统一用技能自带的 `assets/bgm.m4a`（160 秒氛围钢琴，约 -14 LUFS，动态很小）。统一配乐是系列辨识度的一部分，所以默认不换；但在和用户确认方案时要问一句是否更换。项目里 `MUSIC = "bgm.m4a"`，用户换音乐就改这一行（或者用 `--music 文件`）。
- 混音方式：音乐默认压低 6 dB 给音效让位；`m.duck(t)` 在揭晓瞬间让音乐避让；`m.mute(t0, t1)` 做全片唯一一次骤停（放在反转处）；结尾 2.5 秒自动淡出。视频比音乐长时，自动用 2 秒交叉淡化循环。
- **完全不要音乐**（`--music none`）：可以用 `m.pad()` 铺低频 A 小调和弦，用 `m.piano()` 在镜头开头点一个音，只适合临时样片。
- 音效要和画面同一时刻触发：例如对折音效直接用 `FOLD_T` 列表，逐格音效直接用 `CELL_T` 列表。**动画时间和音效时间共用同一份数据**，就不会对不上。
- 成片统一做 `loudnorm=I=-14:TP=-1`（短视频平台常用标准）。音效混音电平用 `fx_gain`（默认 0.55）调。

## 字体

- 引擎会按顺序找字体：思源宋体 / Noto Serif SC → 宋体 simsun → macOS 宋体。用户装了思源宋体，画面会明显更精致。
- 宋体在大字号下笔画太细，引擎会自动加 1~3 px 同色描边来加粗（`SONG_IS_THIN`）。
- 上标（2⁴²）不要用 Unicode 上标字符，Georgia 没有 ⁴ 这类字形。用 rich 的 dy 偏移：`("42", CREAM, 16, 'geo', False, -12)`。

## 自查清单（每次 preview 都过一遍）

- 字幕区（y 940~1040）有没有被动画元素压住；角标区（y < 150）有没有被挤到
- 同一屏是不是只有一句在动
- 每个数字、年份、人名和分镜稿的事实核查备注一致
- 情绪色（红）只在反转处出现
- 每 3~5 秒有没有新的视觉变化，有没有超过 5 秒的「空镜」
- 镜头切换处有没有闪一帧黑或者跳帧（在镜头边界前后各 0.1 秒抽帧）
