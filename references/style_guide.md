# 风格指南：「知识大赏」黑金纪录片风

这类视频是用代码做出来的动态信息图，**没有人声**，靠字幕、动画和背景音乐讲完一个知识点。

## 一句话定义

深色底 + 一两种强调色 + 衬线字体 + 档案式角标 + 一镜到底的元素变形 + 动态生成的数据可视化 + 一行描金字幕 + 氛围配乐。观感像「博物馆展签会动」。

## 视觉规范

| 项 | 规范 | 为什么 |
|---|---|---|
| 底色 | 近黑暖底 `#0B0A08`，加暗角和极淡颗粒 | 纪录片质感；颗粒让纯色底不显得「电脑生成」 |
| 强调色 | 一种主色（金 `#C9A35B`），最多再加一种情绪色（警示红 / 跑道红 / 夜空蓝） | 颜色越少越高级；第二种颜色只在情绪转折时出现，才有冲击力 |
| 正文 | 米白 `#ECE4D4`，次要文字暖灰 | 纯白太刺眼 |
| 字体 | 中文宋体/明朝体（思源宋体最好），英文和数字用 Georgia / Garamond 类旧式数字 | 衬线 = 学术、书卷气；旧式数字高低错落，有古籍感 |
| 发光 | 关键词、曲线、亮点加金色辉光 | 「被点亮」的感觉，引导视线 |
| 角标 | 左上：大号年份/数值 + 小字「地点 · 人物」；右上：英文原著名（斜体）+ 中文书名 + 红色小印章；右下：栏目水印 | 每一帧都像档案卡，可信度高、截图好看 |
| 字幕 | 底部居中一行，40 号宋体，每句 ≤ 25 字，关键词描金发光（每句 1~2 处） | 静音也能看懂；关键词是记忆点 |
| 转场 | 几乎不硬切（全片最多几次）。元素淡出、变形、镜头推拉，或短暂压暗再亮起 | 像在一个空间里连续发生，而不是翻 PPT |
| 节奏 | 每 3~5 秒必须有新的视觉变化；单个镜头 4~10 秒 | 完播率 |
| 时长 | 90~150 秒 | 刚好讲完一个概念 + 一个反转 |
| 画幅 | 横屏 1920×1080（默认）；竖屏时把主体放中间 60% 区域 | — |

## 三种叙事子风格（按题材选）

- **比喻贯穿型**（黑 + 一种情绪色如跑道红 + 白）：一个比喻贯穿全片，例如「跑道中途 → 深渊上的桥」，火柴人表演情绪。适合哲学 / 心理题材。
- **时间线型**（黑 + 金）：左上角大号年份逐个推进，每个年份对应一个人物、一个实验动画，例如落珠堆出正态分布、投针算出 π。适合数学 / 科学史。
- **案例 + 反转型**（黑 + 金 + 深蓝）：用两个案例讲出一个概念，再回头揭穿第一个案例，最后来一个反转，例如讲故事的人自己也成了故事的一部分。适合认知偏差 / 统计。《指数的形状》也属于这一型。

## 常用镜头类型（都在 example_video.py 里有实现）

| 镜头 | 用途 | 示例函数 |
|---|---|---|
| 物件特写 + 简单动作 | 开头钩子：一张纸、一颗骰子、一只猫 | `shot1` |
| 侧视 + 参照物 + 计数器 | 让抽象数量有体感（10 次对折 ≈ 一本书） | `stack_scene` |
| 大字提问 + 选项卡 | 让观众先猜，制造参与感 | `question_scene` |
| 对数刻度尺度旅行 | 数量级跨越极大时（从毫米到月球） | `shot5` |
| 标题卡 | 第一个案例讲完、观众被勾住之后才出标题 | `vkit.title_card` |
| 网格逐格点亮 + 数据面板 | 翻倍、累积、概率的逐步展开 | `chess_scene` 上半 |
| 方格阵列计数 | 把巨大数字换算成「多少个 X」 | `chess_scene` 中段 |
| 双柱对比破框 | 强调悬殊：一个看不见，一个冲出画面 | `chess_scene` 下半 |
| 聚光灯 + 引语打字机 | 名人名言、原文引用 | `bartlett_scene` |
| 容器 + 时钟 + 警示 | 倒计时、临界点、「最后 5 分钟」 | `bottle_scene` |
| 曲线生长 / 变形 | 趋势、模型、反转（指数 → S 曲线） | `scurve_scene` |
| 火柴人站在图上 | 把观众放进图里：「你在这里」 | `person_scene` |
| 双曲线对比 | 两种选择的长期结果 | `compound_scene` |
| 金句卡 | 结尾升华，两行居中，后一行描金 | `sentence_scene` |

## 别做的事

- 别用三种以上的颜色，别用渐变彩虹、霓虹蓝紫：会立刻变成「PPT 模板」。
- 别整屏变色做警示：试过整屏变红，很脏。改成画面四周泛红（`alarm(t)`）。
- 别让动画元素压住底部字幕区（y > 940）：例如长柱子要在字幕上方渐隐。
- 别让同一屏同时有两句话在动：观众只能读一行。
- 别用无出处的「名人名言」：例如「复利是世界第八大奇迹——爱因斯坦」是伪引语。查不到出处就不用，或者干脆当彩蛋揭穿。
