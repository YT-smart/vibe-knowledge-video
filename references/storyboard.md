# 选题、文案与分镜

## 选题公式

**一个经典概念 + 一个反常识的钩子案例 + 能做成动态图的过程 + 结尾反转 / 金句。**

好选题的检查：
- 概念是「听说过但讲不清」的（复利、认知偏差、哲学概念、概率论）。
- 有一个**具体到数字**的反常识开头（「纸对折 42 次能到月球」「检测准确率 99%，阳性却只有 9% 真患病」）。
- 核心过程**能动起来**：翻倍、累积、分布浮现、曲线变形、样本被筛掉……能被模拟的概念最好看。
- 有一个**反转**：前面讲的结论被推翻，或者讲故事的人自己成了故事的一部分。

热门概念往往已经有人做过，要**错开角度**。例如复利常被讲成「投资要坚持」，《指数的形状》就讲「直觉为什么会失灵」。

## 文案结构（无旁白，全靠字幕）

1. **钩子（0~5 秒）**：一个具体场景或数字，或者直接向观众提问。第一句话就要有画面。
2. **展开案例 1（到 30 秒左右）**：让观众猜 → 揭晓，答案要远超预期。
3. **标题卡**：观众被勾住以后才亮出概念名。
4. **案例 2 / 历史线 / 原理（中段）**：换一个角度再证明一次，或者按年份推进。中间放一句名人原话（必须有出处）。
5. **反转（约 70% 处）**：推翻前面的结论，或者揭示代价 / 极限，配合情绪色和音乐骤停。
6. **落到「你」**：角标换成「2026 / 此刻 · 你」，把概念接到观众自己的生活上。
7. **金句 + 片尾标题卡**：两行，第二行描金。

字幕规则：
- 一屏只有一句，≤ 25 字；用逗号、破折号制造停顿（「而引擎中弹的那些——」）。
- 每句最多 1~2 个【关键词】，用【】标出（引擎会描金发光）。
- 字幕停留时间 ≈ 字数 × 0.25 秒 + 1.5 秒，最短 3 秒。
- 字幕和画面要同步：画面揭晓数字的那一刻，字幕再说出数字。

## 事实核查（写分镜时就做，别等渲染完）

- 每个数字都当场算一遍，把公式写进分镜稿的「事实核查备注」，例如 0.1 mm × 2⁴² = 43.98 万 km。《指数的形状》初稿写成「第 64 格就要近千年的产量」，算下来单格只有约 460 年、整张棋盘才是约 887 年——是在制作中途才发现的。
- 有假设的估算，就在画面角落用小字注明假设（「按每粒 25 mg 估算」「理论值」）。
- 引语要能找到原始出处（演讲、书名、年份）；伪引语不用。
- 年份、地点、人名放进角标，和事实核查备注一一对应。

## 分镜稿格式

写成 Markdown 文件，放在用户的项目目录里，先给用户看。完整范例见 `example_storyboard.md`。必须包含：

1. 标题、时长、一句话主题
2. 差异化定位（和同题内容有什么不同）
3. 视觉规范表（这一条的强调色、情绪色、主视觉母题、配乐走向）
4. **分镜表**：`# | 时间 | 画面 | 字幕（【】标关键词）| 角标`
5. 事实核查备注
6. 2~3 个可选标题
