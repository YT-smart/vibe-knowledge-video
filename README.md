# Vibe Knowledge Video · 知识大赏

**给 AI 一个知识点，做成黑金纪录片风的科普短视频。**

用动态画面和字幕讲清概率、数学、认知偏差、历史经济与哲学心理。默认横屏 1080p、无旁白，搭配背景音乐和音效。

## ✨ 能做什么

- **从选题到成片**：让 AI 帮你想选题、写分镜、核查数字，再制作动画、字幕与配乐。
- **先看样片再继续**：先做 10～30 秒，确认风格和节奏后，再制作完整版。
- **用自然语言修改**：告诉 AI 哪个镜头要改、字幕怎么调，就能继续迭代。

## 🚀 安装

把下面这句话发给支持 Skill 的 AI 助手：

```text
请帮我安装这个 Skill：https://github.com/YT-smart/vibe-knowledge-video
```

安装和制作所需的环境交给 AI 准备。

## 💬 怎么用

**做一个样片：**

```text
用 vibe-knowledge-video skill，做一个《运气的形状》的视频，先给我 10 秒样片。
```

**没想好选题：**

```text
用 vibe-knowledge-video skill，推荐 10 个适合做成知识科普视频的选题。
```

**制作完整版：**

```text
用 vibe-knowledge-video skill，把「生日悖论」做成约 2 分钟的视频，先给我看分镜。
```

**修改视频：**

```text
把第 4～7 秒的动画放慢，字幕再简短一点。
```
